GitHub托管一个之前的一个我觉得不错的展示的前端页面，方便我下次复刻使用这个页面。

提示词：

帮我做一个**项目进度甘特图**网页，用 **ECharts 5**（CDN 引入即可，别用别的库）+ 纯 JavaScript，不用框架。

**大致长这样：**

- 横轴是时间，从项目开始到结束
- 纵轴一行一个任务，从上往下排
- 每个任务一根彩色横条，横条右边用小引线连着任务名
- 横条颜色按状态分：绿=已完成、蓝=进行中、橙=计划
- 最上面一根贯穿整个项目周期的浅紫色长条，写上"项目工作时间"
- 最下面一行是里程碑，用小菱形标出来
- 用红虚线标出"今天"的位置
- 顶部有标题、图例，还有一个日期选择框能调整图表显示到哪天为止

**技术要点：**

ECharts 没有现成的甘特图类型。请用**时间轴 + 类目轴**组合，任务用 `type: 'custom'` 自定义系列，在 `renderItem` 里自己把日期换算成横条。里程碑直接用内置的菱形符号，不用自己画。

**两个要求：**

1. 数据和配置放一个 JSON 文件里，换项目只改这个文件，不碰代码
2. 任务的结束日期要**包含当天**（长度要加 1 天），否则每根条都会短一天
